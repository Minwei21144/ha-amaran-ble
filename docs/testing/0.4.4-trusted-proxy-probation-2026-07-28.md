# Amaran BLE 0.4.4 Trusted Proxy Probation Validation

Test date: 2026-07-28

Home Assistant Core: 2026.7.2

Bluetooth path: ESPHome Bluetooth Proxy

Mesh: existing Amaran Desktop / Sidus Mesh with four fixtures

## Goal

Version 0.4.3 used a 30-second stability threshold before reporting
`connected`, but extended testing found that a candidate could still disconnect
after roughly 90 seconds. Version 0.4.4 separates usability from long-term
trust:

- At 30 seconds, the connection becomes operational and Home Assistant can
  control fixtures.
- At 120 seconds, the candidate becomes trusted and is saved as the preferred
  proxy.
- A disconnect between 30 and 120 seconds is classified as
  `probation_disconnect` and quarantines the candidate for 300 seconds.

This does not delay the point at which users can control fixtures.

## Safety boundary

Only the custom integration, tests and project documentation were changed. The
test did not modify:

- Home Assistant native Bluetooth configuration.
- ESPHome Bluetooth Proxy firmware or configuration.
- BTHome or another integration.
- Mesh keys, pairing data or Mesh topology.

## Probation fault injection

T2c #2 became operational after 40.154 seconds. Power was removed while
`connected_seconds=31.7` and `connection_trusted=false`.

| Event | Time after power removal |
| --- | ---: |
| Proxy loss classified | 37.733 s |
| Initial quarantine remaining | 294.3 s |
| 200x entered `stabilizing` | 63.183 s |
| 200x restored `connected` | 92.223 s |

The disconnect was classified as `probation_disconnect`, not
`stable_disconnect`. After T2c #2 power was restored, the next ownership cycle
respected its remaining quarantine and selected the 200x.

## Result

Version 0.4.4 met the single-variable goal:

1. User control still becomes available after the 30-second operational
   threshold.
2. A candidate that survives only 30-90 seconds is not saved as trusted.
3. Physical power loss during probation creates the expected classification and
   quarantine.
4. Another fixture can take over while the failed candidate is quarantined.
